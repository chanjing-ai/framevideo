# 视频任务规划

将连续分镜 Clip 聚合为适合视频模型一次生成的 Shot。目标不是按镜头语言机械切分，而是识别“核心生成状态”是否跃迁：只要主体、段落目标、行为目标、信息任务、情绪张力和生成重点仍稳定，默认合并。

## 工作顺序

1. 先通读完整场景或一组连续 Clip，以 4 到 8 个相邻 Clip 为一组观察，不要逐个 Clip 线性保守切分。
2. 先标出核心生成状态的跃迁边界，再在边界内部寻找最大可合并连续段。
3. 对每个最大候选段检查是否存在必须拆开的强边界。
4. 再检查主视觉中心是否仍围绕同一主体、关系组或事件核心。
5. 再检查是否属于同一动作链、情绪链、表达链或直接反应链。
6. 最后检查时长和复杂度是否适合一次生成。单个 Shot 通常不超过 15 秒，但不要为了凑满 15 秒硬合并。

若没有明确强切分信号，保留合并结果，不要回退为保守拆分。

## 核心生成状态

判断相邻 Clip 是否应合并，优先看是否仍维持同一个核心生成状态：

- 核心主体 / 关系：主要在拍谁，或哪组关系。
- 核心段落目标：这一段主要在完成什么。
- 核心行为目标：这一段主要在做什么。
- 核心信息任务：这一段主要想让观众知道什么。
- 核心情绪张力：这一段主要在推进什么情绪。
- 核心生成重点：模型此刻最需要稳定生成的是什么。

核心状态没有明显改变时，默认合并；只有核心状态发生明确跃迁时，才优先切分。

## 默认合并

相邻 Clip 满足以下条件时，默认合并：

- 仍属于同一个核心生成状态。
- 仍在推进同一个段落目标。
- 主视觉中心仍围绕同一主体、关系组或事件核心。
- 后一个 Clip 是前一个 Clip 的自然延续、阶段推进、组成部分或直接后果。
- 合并后通常不超过 15 秒。
- 合并后不会让一个 Shot 同时承担多个彼此独立且同等重要的高权重任务。

阶段变化不等于新 Shot。同一段落目标下的“出现 -> 站定 -> 起势 -> 开口 -> 加强 -> 落句”、“观察 -> 靠近 -> 触碰 -> 确认”、“惊醒 -> 茫然 -> 识别 -> 发问”、“取物 -> 展示 -> 使用”等，应默认视为同一连续段。

## 不应单独触发切分

以下变化通常只是同一状态内部展开，不要单独作为切分理由：

- 景别变化，远景 / 中景 / 近景 / 特写。
- 局部特写，手、眼、嘴、道具、门把、脚步、衣角、物件细节等。
- 同一主体动作的分阶段展开。
- 同一情绪的连续推进。
- 同一表达过程中的铺垫、停顿、起势、强调、落点。
- 同一事件中的短反应镜头。
- 同一关系组内部的短暂主体切换。
- 正反打、过肩、侧拍等常规镜头语言变化。
- 很短的 OS / VO / 内心判断补充，且仍服务当前段落。
- 主体动作与其直接后果的连续呈现。

只要这些变化仍共同服务同一个段落目标，就优先合并。

## 强切分信号

只有出现明确强边界时，才优先切为新 Shot：

- 核心段落目标改变：如建立环境 -> 主角行动，威胁压迫 -> 谈判交易，背景说明 -> 责任交接。
- 核心行为目标改变：如观察 -> 行动，搜索 -> 发现后解释，对峙 -> 出手，表达 -> 逃离。
- 核心信息任务改变：如呈现现状 -> 说明原因，情绪宣泄 -> 给出事实，外部事件 -> 内部判断。
- 核心观察重点改变：如从 A 的行为转为 B 的独立反应，新人物进入并开始主导局面。
- 核心情绪张力改变：如困惑 -> 恐惧，悲伤 -> 冷静判断，试探 -> 威胁，玩笑 -> 敌意。
- 空间或时间明显变化：地点变化、室内外切换、明确时间跳跃、光线 / 时段 / 空间结构显著改变。
- 合并后复杂度明显过高：一个 Shot 同时承担多个彼此独立的高权重任务。

自然递进不等于任务过多。如果多个 Clip 仍共同完成同一个段落目标，不要误拆。

## 链条归属

动作链、情绪链、表达链优先合并：

- 连续动作链：逼近 -> 出手 -> 命中 -> 后果；拿起 -> 展示 -> 使用；跌倒 -> 爬起 -> 继续动作。
- 连续情绪链：茫然 -> 警觉；哭求 -> 克制 -> 强撑；震惊 -> 难以置信 -> 发问。
- 连续表达链：看向众人 -> 起势 -> 开口 -> 强调 -> 落句；思考 -> 判断 -> 得出结论；试探 -> 加码 -> 逼问。

不要把同一表达过程机械拆成多个小功能段。

## 反应镜头

反应镜头按归属判断，不按形式切分：

- 并入前段：反应只是前一动作、台词或状态变化的直接后果，如出手后对方惨叫、开口后众人停步、威胁出口后现场哄笑。
- 并入后段：反应开始引出新的观察重点、判断或事件，如看见异常后开始独立怀疑，听到门响后转入新威胁，新角色挤出并开始主导局面。

## OS / VO / 回忆 / 心理段

优先判断它是否形成新的独立认知任务：

- 很短的补充、仍服务当前动作或情绪、只是同一认知链一环时，可并入前后段。
- 承载大量新信息、形成独立回忆或判断过程、从外部事件切换到内部认知主导时，优先单独成段。
- 同一主题的连续认知链不要过度拆碎。

## 复杂度控制

即使总时长未超过 15 秒，若合并后让一个 Shot 同时承担多个彼此独立的高权重任务，也应拆分。常见高权重任务包括强动作冲突、群体复杂反应、大量台词推进、心理独白 / 回忆、背景说明、关系逆转、威胁进入、责任交接、利益谈判。

## 视觉连续性检查

Shot 聚合不仅检查叙事任务，也必须检查一次生成内的视觉稳定性。候选段合并前，确认以下视觉条件是否仍连续：

- 光线方向和色温是否稳定：窗光、月光、台灯、霓虹、屏幕光等动机光源不能在同一 Shot 内无原因跳变。
- 主体轴线和视线方向是否稳定：正反关系、对峙方向、人物面向和视线留白不能突然反向，除非剧情明确发生转身、换位或新观察重点。
- 运动方向是否连续：追逐、逼近、退后、跌倒、起身等动作方向应保持可理解的空间逻辑。
- 构图重心是否稳定：同一 Shot 内可以有景别变化，但主视觉中心应围绕同一主体、关系组或事件核心，不要从人物情绪突然跳到独立道具任务。
- 景深和焦点任务是否稳定：浅景深人物情绪段不要突然承载复杂群体关系；深景深空间关系段不要突然变成孤立细节特写任务。
- 服装、道具、发型、伤痕、手持物、站位、门窗开合等连续性是否可维持。

如果候选段叙事上可合并，但出现明显光线、轴线、空间、道具或主体一致性风险，应优先拆分，或在合并理由中说明该风险可由同一核心动作自然消化。

## AI 视频可生成性风险

即使核心生成状态未变，以下情况也可能需要拆分：

- 同一 Shot 内同时出现多人复杂调度、强动作冲突和大量台词。
- 主体需要明显变装、变脸、年龄变化、伤痕突然出现或消失。
- 手部精细动作连续变化过多，如写字、拆装、打结、复杂持械、频繁换道具。
- 镜头内完成大幅空间转场，如室内到室外、车外到车内、楼上到楼下。
- 同一 Shot 同时要求强特效、强表演、复杂群体反应和关键道具变化。

这些不是自动强切分信号；只有当它们会破坏一次生成的主体稳定性、空间连续性或关键信息清晰度时，才拆开。

## 争议处理

一个 Clip 既可并前也可并后时，按以下优先级判断：

1. 优先并入同一动作链 / 情绪链 / 表达链。
2. 优先并入同一核心生成状态更完整的一组。
3. 优先并入主视觉中心更稳定的一组。
4. 优先并入核心段落目标更一致的一组。
5. 若两边都合理，优先减少碎片化。
6. 不能为了减少碎片化而破坏段落完整性。

## 输出流程

正式给出 Shot 划分前，必须先完成两步分析并在答案中体现：

1. 列出最大可合并候选段：按连续片段寻找每个场景中可能本质上属于同一完整段落的 Clip 组。
2. 检查候选段内部强切分边界：只有存在明确强切分信号时，才把候选段拆开。

最终输出每个 Shot 时，建议包含以下分析字段（这是工作文档，用于推理过程；正式交付给下一阶段时使用末尾的"Shot 交接格式"）：

- 包含的 Clip 编号
- 总时长
- 段落目标 / 微事件名称
- 主视觉中心
- 核心行为目标
- 核心信息任务
- 视觉连续性检查
- AI 视频可生成性风险
- 合并理由
- 不并入前后段的理由

输出要体现：先标出核心状态跃迁边界，再在边界内主动合并为最大稳定连续段；未出现强切分信号时，不得为了保守而拆碎。

## Shot 交接格式

将本文件输出传给 `single-video-prompt-polisher` 前，按以下结构规范化每个 Shot：

```text
Shot编号：
包含Clip：
总时长：
段落目标 / 微事件：
主视觉中心：
核心行为目标：
核心信息任务：
情绪张力：
场景与时间：
连续性约束：
必须保留的台词：
关键动作链：
镜头语言建议：
光影/滤镜建议：
动态场景/环境特效：
参考资产：
AI视频可生成性风险：
不并入前后段的理由：
```

映射规则：

- `包含Clip` 必须列出该 Shot 包含的所有 Clip 编号。
- `总时长` 默认为所含 Clip 时长总和，除非用户要求重新定时。
- `必须保留的台词` 必须完整保留原台词，此阶段不要为了润色改写台词。
- `关键动作链` 应将 Clip 动作合并为连续进程，例如 `观察 -> 靠近 -> 触碰 -> 确认`。
- `连续性约束` 应保留稳定的人物身份、道具、光线方向、轴线和空间状态。
- `镜头语言建议` 可以把多个 Clip 的摄影选择概括为一个可执行生成策略，不要把彼此矛盾的运镜塞进同一个 Shot。

## 自检

Shot 划分完成后简短检查：

1. 是否存在未出现强切分信号却被拆开的保守碎切，若有则重新合并。
2. 是否存在合并后时长明显超过 15 秒，或同一 Shot 同时承担多个独立高权重任务的情况，若有则拆分。
3. 每个 Shot 的视觉连续性是否稳定：光线、轴线、服装、道具、站位在 Shot 内无无原因跳变。
4. 是否完整保留了所有原始台词，没有在聚合过程中遗漏。
