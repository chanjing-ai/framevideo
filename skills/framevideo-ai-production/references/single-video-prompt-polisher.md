# 单视频提示词润色

## 输出契约

只输出纯文本。不要使用 Markdown 代码块、表格、解释性旁白或额外说明。以下代码块仅为格式示意，不是实际输出样式。

如果原始提示词包含资产编号或资产标签，必须在最开头单独放置参考图资产声明区。每个被提到的资产单独一行，并完整保留原始标签格式，例如：

`<<ref>>是xxx`

然后按照自然叙事节拍，将原始故事拆分为多个连续镜头。每个镜头必须包含完整提示词结构，并严格使用以下字段顺序：

```text
镜头1，【时长】x秒
【主体】
【场景】
【核心动作】
【台词】
【镜头语言】
【光影/滤镜】
【连续性约束】
【动态场景/环境特效】
```

所有镜头之后，必须原样追加：

```text
严格按照分镜脚本进行生成，参考上传图的人物形象、场景和道具。不要生成字幕。不要改变人物身份。不要改写台词。
```

## 字段规则

- `镜头序号与时长`: 按自然顺序编号为 `镜头1`、`镜头2` 等。根据节奏和叙事需要选择时长。
- `【主体】`: 必填。用 `<角色名> + 动作、表情、道具交互` 精确命名焦点主体。将同一角色的动作、表情、道具交互合并成一个逗号分隔的长句。除非原文只提供了这类称呼，否则不要使用 `他`、`她`、`那个人`、`男人`、`女人` 等代词或模糊标签。若需要陪体，紧跟主体后写成 `, <陪体角色名> + 动作/表情`；通常不超过一个陪体。
- `【场景】`: 写清拍摄地点和时间，例如 `夜晚的巷道`、`午后客厅`。只在不违背原文时补充关键环境细节。
- `【核心动作】`: 将平铺直叙改写为高度可视化的动作。聚焦本镜头最强的情绪、叙事或信息节拍。保持一到两句。
- `【台词】`: 必填。完整保留分配到本镜头的对白或独白，不改写、不删除、不翻译、不加词。使用 `说话者(语气): "原文台词。"` 格式。没有台词则写 `无`。若因时长需要拆分台词，只放入当前镜头承载的完整语义单元。
- `【镜头语言】`: 必填。明确景别、机位高度/角度、节奏和构图策略，例如 `近景，平视慢推，三分法构图，张强位于画面右侧并向左留出视线空间`、`特写，低机位微仰快切，中心构图压住李梅的脸`、`中景，越过张强左肩平视拍李梅，前景肩膀形成遮挡压迫`、`POV（张强）快速摇移，门框形成框中框构图`。避免 `侧面` 这类模糊方向，改写为 `从左侧平视` 或 `越过X左肩拍Y`。
- `【光影/滤镜】`: 描述动机光源、光线方向、明暗对比、色温和质感/滤镜建议。优先使用可执行的电影语言，例如 `窗外冷月光从左侧切到张强半张脸，室内暖灯压暗背景，低调高反差，轻微胶片颗粒`。避免 `高级灯光`、`电影质感` 等空泛词。
- `【连续性约束】`: 列出本镜头必须维持的视觉连续性要素，例如 `林晚穿黑色风衣，左脸有划痕，手持打火机`、`陈默站在门左侧，视线向右`。若输入 Shot 中无特殊连续性约束，写 `无`。
- `【动态场景/环境特效】`: 在有用时加入物理动态、小特效、相关环境声或音效，例如窗帘摆动、碎玻璃、雨滴、尘埃、烟雾、霓虹反光、脚步声、关门声。需要时标注 J-cut 或 L-cut，例如 `雨声（J-cut先入）`、`门砰声（L-cut延续至下镜）`。没有则写 `无`。

## 电影化约束

专业参数要对提示词友好。除非用户明确要求技术摄影参数，否则用视觉效果和人物关系表达，不写硬件规格。

`【镜头语言】` 中尽量包含：

- 景别：特写、近景、中景。只有输入的 Shot 中已明确包含全景或远景，或用户明确要求时，才可使用全景或远景；不得自行新增。
- 机位角度/高度：平视、低机位、高机位、俯拍、仰拍、越肩、POV。
- 运镜/节奏：定镜、慢推、拉远、横移、跟拍、手持微晃、快切、闪切。
- 构图：三分法、中心构图、前景遮挡、框中框、负空间、纵深构图、引导线构图。
- 画面重心：写明主体位置或视觉权重，例如 `人物偏画面左侧`、`脸部占画面三分之一`、`背景人群虚化成压迫色块`、`向角色视线方向留白`。

`【光影/滤镜】` 中尽量包含：

- 动机光源：窗光、台灯、手机屏幕、电视、车灯、霓虹、烛火、月光、走廊顶灯。
- 光线方向：侧光、逆光、顶光、斜侧光、低位光、门缝漏光。
- 明暗关系：低调高反差、柔和低反差、半脸阴影、剪影、轮廓光勾边、背景压暗。
- 色彩关系：冷月光、暖钨丝灯、冷暖对比、荧光偏绿、钠灯暖黄、屏幕冷光。
- 质感：浅景深、深景深、背景虚化、前景虚化、胶片颗粒、柔光、轻微镜头眩光、低饱和、高对比。

不要要求精确焦距、光圈、ISO、快门角、摄影机型号、镜头品牌、灯具型号、瓦数或物理布灯距离。必要时使用焦段感描述，例如 `广角感强化狭窄空间压迫`、`标准镜头感保持真实观察`、`中长焦压缩空间并突出人物孤立`。

避免连续镜头重复同一视觉配置。同场景相邻镜头至少改变以下两项：景别、机位高度、视线方向、构图、运镜、光影重点。

## 工作流程

1. 识别资产标签，并在任何镜头文本之前声明每个被引用资产。
2. 从原始提示词中提取角色名、地点、道具、台词和关键剧情节拍。
3. 将故事拆成连续镜头。优先保证每个镜头只有一个清晰动作、情绪或信息节拍。
4. 保留原始人物信息和台词。不要发明新台词、改名或添加无依据剧情。
5. 使用清晰、可执行、面向画面生成的表达。每个字段保持一到两句，通常不超过三行。
6. 若原文包含敏感或不合规内容，在保留故事意图的同时，按安全要求弱化或象征化视觉呈现。
7. 以指定生成说明结尾，且结尾后不要添加任何内容。

## 自检

输出完成后简短检查：

1. 是否完整保留了原台词，没有改写、删除、翻译或添加。
2. 是否完整保留了原人物名、人物关系和事件顺序，没有新增无依据情节。
3. 参考资产标签是否在开头单独声明，格式是否原样保留。
4. 所有镜头之后是否追加了三条禁止项结尾语。
5. 【连续性约束】字段是否覆盖了服装、道具、伤痕、站位等关键跨镜一致性信息。
