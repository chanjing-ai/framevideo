# 工作流交接格式

格式速查手册。定义 Clip、Shot、Final Prompt、Chanjing AIGC Plan 的标准交接格式及映射规则。决策树和管线描述见 `SKILL.md`。

## 标准 Clip 交接格式

将 `storyboard-script-generation` 输出传给 `video-task-planning` 前，按以下结构规范化每个分镜：

```text
Clip编号：
场景ID：
原镜号：
时长：
核心段落目标：
主视觉中心：
核心行为/情绪：
信息任务：
【景别】
【运镜】
【视角/构图】
【主体描述】
【光影】
【台词】
【音效】
连续性标签：人物 / 服装 / 道具 / 站位 / 光线 / 轴线 / 空间状态
生成风险：无 / 手部精细动作 / 多人调度 / 强动作 / 复杂特效 / 空间转场 / 大量台词
备注：
```

映射规则：

- `原镜号` 来自 `storyboard-script-generation` 的 `镜号`。
- `时长`、`景别`、`运镜`、`主体描述`、`光影`、`台词`、`音效` 直接复制，除非确实需要规范化。
- `核心段落目标`、`主视觉中心`、`核心行为/情绪`、`信息任务` 根据分镜节拍推断，不得发明新剧情。
- `连续性标签` 只记录保持相邻 Clip 视觉稳定所必需的信息。
- `生成风险` 标注的是 AI 视频生成难点，不是普通电影调度复杂度。

## 标准 Shot 交接格式

将 `video-task-planning` 输出继续转向最终提示词写作时，使用以下格式：

```text
Shot编号：
包含Clip：
总时长：
段落目标 / 微事件：
主视觉中心：
核心行为目标：
核心信息任务：
情绪张力：
场景与时间：
连续性约束：
必须保留的台词：
关键动作链：
镜头语言建议：
光影/滤镜建议：
动态场景/环境特效：
参考资产：
AI视频可生成性风险：
不并入前后段的理由：
```

映射规则：

- `包含Clip` 必须列出该 Shot 包含的所有 Clip 编号。
- `总时长` 默认为所含 Clip 时长总和，除非用户要求重新定时。
- `必须保留的台词` 必须完整保留原台词，此阶段不要为了润色改写台词。
- `关键动作链` 应将 Clip 动作合并为连续进程，例如 `观察 -> 靠近 -> 触碰 -> 确认`。
- `连续性约束` 应保留稳定的人物身份、道具、光线方向、轴线和空间状态。
- `镜头语言建议` 可以把多个 Clip 的摄影选择概括为一个可执行生成策略，不要把彼此矛盾的运镜塞进同一个 Shot。

## Final Prompt 输入格式

将 Shot 转换为 `single-video-prompt-polisher` 输入时，提供以下紧凑原始提示词：

```text
参考资产：
场景与时间：
人物与关系：
连续性约束：
剧情动作：
必须保留的台词：
镜头语言方向：
光影/滤镜方向：
环境动态与音效：
禁止项：不要生成字幕；不要改变人物身份；不要改写台词
```

如果用户需要每个 Shot 各一条提示词，则逐个 Shot 单独运行润色，不要把无关 Shot 合并成一条提示词。

## Chanjing AIGC Plan 输入格式

当用户需要蝉镜 AIGC 真实生成图片/视频时，不停在 Final Prompt。将 Shot 转换为 `chanjing-aigc-handoff` 输入：

```text
项目路径：
生成目标：image / video / image+video
Shot编号：
包含Clip：
总时长：
生成用途：主视觉 B-roll / 背景 / 参考图 / 转场素材 / 产品展示 / 抽象视觉
主视觉中心：
场景与时间：
连续性约束：
关键动作链：
镜头语言建议：
光影/滤镜建议：
动态场景/环境特效：
参考资产：
必须保留的台词：
AI视频可生成性风险：
FrameVideo回填位置：start / duration / trackIndex / avoid
禁止项：不要生成字幕；不要改变人物身份；不要改写台词；不要直接使用远程URL
```

映射规则：

- `生成目标` 根据用户目标和 Shot 内容选择。静态概念、参考图、背景板用 image；动态 B-roll、环境动效、展示片段用 video。
- `FrameVideo回填位置` 来自旁白、字幕、Shot 时长或人工估计。若没有时间轴，先保留相对顺序，后续由 FrameVideo composition 定时。
- `必须保留的台词` 只作为表演/节奏参考；除非蝉镜模型明确支持口型/对白，不要求 AIGC 准确生成台词。
- 具体模型、payload 字段和提交方式不在本文件硬编码，交给 `chanjing-aigc-handoff.md` 和 `../../chanjing-digital-human/references/ai-creation.md`。
